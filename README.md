# TemplateForge

Single-seller digital templates shop — business & productivity templates at $15–$49, sold via Ko-fi. This is **not** a marketplace: there is one seller, no vendor accounts, no seller signup.

## Site

Pure static HTML/CSS/JS in `site/` (`index.html`, `styles.css`, `script.js`, `sitemap.xml`, `robots.txt`). No build step, no CDNs, no external fonts or images — deploy as-is to GitHub Pages (`oddjack0.github.io/templateforge/`).

The catalog has six products with a working JS category filter (Spreadsheets / Planners / Business Forms / Bundles):

## How sales work — read before editing links

- **All site cards link to the Ko-fi shop: https://ko-fi.com/oddjack/shop** — every "Get it on Ko-fi" CTA points there, not to individual product pages.
- **Individual Ko-fi listings go live one at a time, as the product team finishes each template file.** Until a given template's file is finished, tested, and listed, the shop link is the correct destination. When a listing does go live, its card CTA may be repointed to that specific listing — and only then.
- Do not invent per-product Ko-fi URLs. If a listing URL isn't confirmed live, the card keeps pointing at the shop.
